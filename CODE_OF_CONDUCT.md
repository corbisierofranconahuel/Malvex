# Codigo de conducta

## Nuestro estandar

Se respetuoso, tecnico y constructivo. El desacuerdo es bienvenido cuando se
enfoca en evidencia, decisiones de diseno y mejoras para el proyecto.

No se acepta el acoso, la discriminacion, las amenazas, la divulgacion de
informacion privada sin permiso ni el uso de los espacios del proyecto para
promover actividades ilegales.

## Alcance

Este codigo se aplica a issues, pull requests, discusiones y otros espacios
oficiales de la comunidad Malvex.

## Aplicacion

Los mantenedores pueden editar, eliminar o rechazar contribuciones y
participaciones que infrinjan este estandar. Reporta incidentes sensibles en
privado mediante el proceso indicado en `SECURITY.md`.
